# محدودیت‌های واقعی اندروید

این سند چیزهایی را ثبت می‌کند که **نمی‌توان** بدون دور زدن امنیت سیستم‌عامل انجام داد. پروژه آن‌ها را دور نمی‌زند.

## تصویر صفحه

- MediaProjection بدون رضایت کاربر غیرقانونی در چارچوب Play policy و از نظر API غیرممکن است.
- پنجره‌های `FLAG_SECURE` (بانک، password manager، برخی پخش‌کننده‌ها) سیاه یا خالی می‌آیند. جایگزین: پیام «این صفحه محافظت شده است»، نه تلاش برای bypass.
- بعضی OEMها capture را در lock screen محدود می‌کنند.
- PIN، Pattern، Password و Biometric نیاز به تعامل فیزیکی دارند. معماری ادعا نمی‌کند قفل را باز می‌کند.

## ورودی

- بدون Accessibility (یا بدون ADB زنده)، ژست تزریق نمی‌شود.
- Accessibility روی بعضی اپ‌های بانکی با `filterTouchesWhenObscured` / anti-overlay محدود می‌شود.
- IME کامل (پیشنهاد واژه، زبان پیچیده) ممکن است با ارسال کاراکتر کامل نباشد. جایگزین: paste از کلیپ‌بورد وقتی مجاز است.

## اعلان

- Notification Listener متن کامل را همیشه نمی‌دهد (پیام‌های حساس، MessagingStyle ناقص).
- Reply action فقط اگر خود اعلان `RemoteInput` داشته باشد.
- Mark as Read فقط اگر action متناظر وجود داشته باشد؛ API عمومی «همه را خوانده‌شده کن» وجود ندارد.

## SMS

- از Android 4.4 مدل Default SMS App برای نوشتن SMS Provider جدی است.
- خواندن inbox با `READ_SMS` ممکن است؛ OEMها و نسخه‌های جدید ممکن است دسترسی پس‌زمینه را محدود کنند.
- آرشیو کامل، MMS پیچیده، RCS (Google Messages) با SMS API پوشش داده نمی‌شود.
- جایگزین عملی: نمایش SMSهای در دسترس + اعلان پیام‌رسان؛ ادغام RCS خارج از محدوده.

## کلیپ‌بورد

- از Android 10 خواندن کلیپ‌بورد در پس‌زمینه تقریباً بسته است.
- از Android 12+ toast سیستم هنگام دسترسی نشان داده می‌شود.
- Sync واقعی دوطرفه فقط وقتی Agent در foreground است قابل اعتماد است.
- جلوگیری از loop با `origin` و `hash` اجباری است؛ متن در Log نمی‌آید.

## USB و تترینگ

- هیچ API پایداری برای «ADB را روشن نگه دار وقتی tethering روشن است» روی همهٔ OEMها نیست.
- به همین دلیل کنترل روی TCP/RNDIS است، نه ADB.

## باتری و پس‌زمینه

- OEM battery saver ممکن است Foreground Service را بکشد. Notification دائم آگاهانه است.
- Doze روی TCP server روی USB معمولاً ملایم‌تر از Wi-Fi است، اما Watchdog لازم است.

## جایگزین‌های عملی وقتی قابلیت کامل نیست

| خواسته | واقعیت | جایگزین در این Suite |
| --- | --- | --- |
| Mirroring همیشه | FLAG_SECURE | Placeholders + هشدار |
| کنترل بدون هیچ permission خاص | OS اجازه نمی‌دهد | Permission Center شفاف |
| SMS کامل مثل اپ پیامک | نیاز به Default SMS / RCS | Adapter محدود + اعلان |
| Clipboard 24/7 | محدود از API 29 | Sync فقط foreground + دکمهٔ Send once |
| باز کردن قفل | نیاز فیزیکی | خارج از محدوده |
